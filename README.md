# MISoul

把「超级小爱」的人格换成你自己的，同时把它每轮塞给模型的大量提示词压下来。

- 人格整份替换：`soul.md` / `prompt.md` / 选工具规则，开关可随时切回官方
- 界面形象：显示名、签名、欢迎语，以及对话页里的品牌文案
- 工具描述压缩：实测 344,199 → 62,330 字（−81.9%），保留格式与适用边界
- 选工具规则：官方 24,067 字 → 663 字，可自定义、可一键恢复
- 工具筛选：按类别（出门 / 工作 / 居家 / 自动），默认不启用
- 工具使用统计：记录每个工具被调用的次数与最近时间
- 先规划后执行（可选）：笼统的界面操作先补一段通用规划要求再执行，含支付动作的指令原样放行
- 定时任务放行（可选）：非会员创建定时 AI 任务时，本地会员校验放行

## 环境

- 超级小爱 `8.3.30.4420`（versionCode 508003030）
- Android 17 / LSPosed 2.2.1 / libxposed API 102
- 作用域：`com.miui.voiceassist`

## 使用

1. 安装后在 LSPosed 中启用模块，作用域勾选「超级小爱」
2. 模块更新后需要结束小爱进程（`am force-stop` 对主进程无效）
3. 打开 MISoul 可在概览页看到真实的注入状态

## 注意

- 混淆类名随小爱版本变化，升级小爱后可能失效，模块会安静降级为官方人格
- 「先规划后执行」改写的只是交给执行方的那句任务文字，模块不代替你点屏幕；与 MiAIPlus 同时开启时，两者可以共存，但控屏会话同时只能一个在用
- 定时任务放行只处理客户端检查，云端额度与校验不受影响
- 仅支持 `com.miui.voiceassist`
